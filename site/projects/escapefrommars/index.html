Escape From Mars

A game created during the Game Design & Development minor.

Source code was thought to be lost, but recovered by decompiling an APK with JADX and refactored to work with a template project created with libgdx-liftoff.

The game is available on the Google Play store.

Source isn't shared at the moment, because it's an older project, there are some uncertainties regarding licensing of assets.
